# 메달리온 파이프라인 실행 가이드 (처음부터 재현하기)

지금 정상 동작 중인 세팅(02: K3s+MinIO / 03: Airflow DAG `medallion_pipeline`)을 아무것도 없는 상태에서
다시 그대로 재현하는 절차. 순서대로 번호만 따라가면 됨.

**사전 준비물**
- Docker Desktop 설치 및 실행 중, **리소스 최소 12코어 / 8GB 메모리 이상** 할당 (부족하면 원본 CSV 처리 중 크래시남 — `02/start.md` 11장)
- Kaggle API 토큰(username, key) — https://www.kaggle.com/settings → API → Create New Token


`IPAddress` 값을 확인. **이 값이 지금까지 쓰던 것과 다르면 다음 4개 파일을 전부 그 값으로 맞춰야 함** (하나라도 빠뜨리면 8/4에 겪은 "executor는 뜨는데 job이 안 뜨는" 버그가 재발함):

- `03/dags/medallion_pipeline.py`의 `S3A_ENDPOINT`

- `02/실습코드/01/02.py`의 `hadoop_conf.set("fs.s3a.endpoint", ...)`
- `02/실습코드/01/03.py`의 `hadoop_conf.set("fs.s3a.endpoint", ...)`

(같은 IP라면 이 단계는 건너뛰어도 됨.)

## 3. k3s RBAC + Secret 준비 (최초 1회 — 또는 `docker compose down/up`으로 `k8s-master-node`가 재생성된 뒤)

```bash
docker exec -it k8s-master-node kubectl create serviceaccount spark --namespace=default
docker exec -it k8s-master-node kubectl create rolebinding spark-role \
  --clusterrole=edit --serviceaccount=default:spark --namespace=default

docker exec -it k8s-master-node kubectl create secret generic kaggle-credentials \
  --namespace=default \
  --from-literal=username=<KAGGLE_USERNAME> \
  --from-literal=key=<KAGGLE_KEY>

docker exec -it k8s-master-node kubectl create secret generic minio-credentials \
  --namespace=default \
  --from-literal=access-key=minioadmin \
  --from-literal=secret-key=minioadmin
```

확인:
```bash
docker exec -it k8s-master-node kubectl get serviceaccount,secret -n default
```
`spark` / `kaggle-credentials` / `minio-credentials`가 보이면 완료. (이미 있는 상태에서 다시 실행하면 `AlreadyExists` 에러만 나고 무해함 — 있으면 그냥 넘어가도 됨.)

## 7. 진행 상황 확인

기본은 **Airflow UI만으로 충분**: Grid 뷰에서 태스크 클릭 → `Logs` 탭. `KubernetesPodOperator`가 `get_logs=True`라서 팟 로그가 그대로 스트리밍됨. `ingest_raw_data → bronze_to_parquet → silver_refine → gold_stats` 순서로 초록색(success)이 되는지 확인.

Spark UI(4040)로 실시간 job/stage 진행을 직접 보고 싶다면(선택사항, 매번 재설정 필요 — `02/start.md` 8~9장 참고):
```bash

# 파일 안 server: https://127.0.0.1:6443 → https://localhost:6443 로 치환
export KUBECONFIG=~/.kube_pysprak02/k3s.yaml
kubectl port-forward svc/spark-live-driver-ui 4040:4040   # 이 Service가 없으면 02/start.md 9장의 yaml로 먼저 생성
```

## 자주 겪는 문제

| 증상 | 원인 | 조치 |
|---|---|---|
| 4040엔 executor가 뜨는데 Job/Stage가 안 뜸 | code-bucket 스크립트 안 엔드포인트 하드코딩이 실제 MinIO IP와 다름 | 2번, 4번 다시 |
| Airflow 태스크가 `RBAC Forbidden`으로 실패 | `spark` ServiceAccount/RoleBinding 없음(k3s 재생성됨) | 3번 다시 |
| ingest 태스크가 Secret 관련 에러 | `kaggle-credentials`/`minio-credentials` 없음 | 3번 다시 |
| bronze 단계에서 리소스 부족/크래시 | Docker Desktop 리소스 부족 | Docker Desktop 설정에서 CPU/메모리 상향 (최소 12코어/8GB) |
| `docker compose down` 후 위 문제들이 한꺼번에 재발 | `k8s-master-node` 재생성 시 k3s 내부 상태(RBAC, Secret, History Server 등) 전부 초기화됨. MinIO 데이터(볼륨 마운트)는 살아있음 | 2번부터 순서대로 다시 |
